# نسخة محلية من واجهة مون ستور

هذه صفحة عربية باتجاه RTL تحاكي البنية والأسلوب العام للصفحة الرئيسية في elv-store.com. افتح `index.html` في المتصفح لعرضها؛ لا تحتاج إلى تثبيت حزم. زر **إدارة الموقع** أسفل الصفحة يفتح لوحة الإدارة، ويمكن أيضاً فتح `admin.html` مباشرة.

## التفاعلات المتاحة

- التبديل بين الباقة الفضية والماسية.
- إضافة المنتجات إلى سلة محلية وحذفها منها.
- البحث في المنتجات، وفتح الأسئلة الشائعة، وتغيير لون معاينة سناب.
- القائمة المتجاوبة على الهاتف ورسالة تجريبية للنشرة البريدية.
- لوحة إدارة لتغيير جميع العبارات الظاهرة، ورفع الشعار وصور الأقسام والمنتجات، وتغيير ألوان الواجهة وإضافة رقم واتساب.
- حفظ محلي بالإعدادات في المتصفح، مع تصديرها كملف JSON واستيرادها على جهاز آخر.

السلة والدفع غير مرتبطين بخدمة دفع حقيقية. عند إضافة رقم واتساب صالح في لوحة الإدارة، يفتح زر واتساب محادثة مع الرقم. الإعدادات والنصوص والصور المخصصة تُحفظ في المتصفح الحالي؛ استخدم ملف النسخة الاحتياطية لنقلها أو استعادتها. الصور والخطوط الافتراضية جُمعت من الأصول التي يعرضها الموقع المرجعي أثناء المعاينة.

الأسعار الافتراضية عُرضت بالدينار العراقي كتقدير تحويل تقريبي من الأسعار السابقة؛ راجعها وعدّلها من تبويب **كل النصوص** قبل استخدام المتجر للبيع.
